## Working through the exercises

Use a configured Hive/Hadoop teaching environment. Read each exercise before executing its statements and replace the original machine-specific file paths with paths in your environment.

The example input files (such as Student1 and Result1) are not included. Prepare comma-separated sample data matching each table definition before running loading statements. Commands reflect the original lab environment and may need adaptation for your installed Hive version.

Use a disposable practice database: some examples overwrite partitions or drop tables. These files are learning notes rather than an automated deployment pipeline.
